# User Manual

In this section, you can find instructions that enable you to contribute to the NBility model.

## Pre-knowledge

Participants of the workshop are expected to have bacis knowledge of the [NBility model](/model/), [ArchiMate](https://www.opengroup.org/archimate-forum/archimate-overview) and [GitHub flow](https://docs.github.com/en/get-started/using-github/github-flow).
